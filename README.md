# synthesis-site

The website for [Synthesis](https://synthesisbioconsulting.com), served by GitHub Pages from the `main` branch.

- `index.html` is the whole site: every page, style and animation. Pages are switched by the address after `#`.
- `CNAME` sets the custom domain. Don't delete it.
- `404.html` sends old addresses to the homepage.
- Favicons, `site.webmanifest`, `robots.txt` and `sitemap.xml` sit beside it.

Any change pushed to `main` is live within a minute or two.
